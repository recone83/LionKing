DOS64 modifications:
- Convert the single static_cast to a C cast.
- Correct enable_operator's declaration to include the implementation's
  third argument (C does not have C++ overloads).
- Name the unused operator_off parameter for C compiler compatibility.
- Remove DOSBox-specific C++ stream save/load-state functions.
- Define phase addition wraparound with unsigned arithmetic and widen
  vibrato products before signed division, avoiding signed overflow.
- Add dosbox.h for the host integer types, bool and INLINE definitions.
- Keep the status register private to avoid colliding with Heretic's status()
  function when linking the C adaptation.

The chip implementation is included once by ../../dos64_opl_core.c, compiled
as ordinary C without structure packing. That wrapper selects OPL3 and
supplies local sine, power-of-two and noise functions for the freestanding
runtime. ../../dos64_opl.c is the MUS/GENMIDI instrument driver; it is not a
copy of DOSBox's host integration or the original DMX driver.

Rebuild the complete application from source with make -C src at the project
root. No binary-only OPL component is required. The LGPL notices in opl.c and
opl.h are preserved.
